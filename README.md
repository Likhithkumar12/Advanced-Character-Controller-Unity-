Advanced Character Controller - Unity

A physics-based advanced character controller for Unity built with a modular Finite State Machine (FSM) architecture. Designed for responsive movement, smooth gameplay feel, and easy extensibility for different game genres.

Features
Physics-based movement using Unity Rigidbody
Finite State Machine (FSM) architecture
Smooth player movement and rotation
Jumping and air control
Ground detection system
Sprint / Walk support
Modular and extensible code structure
Camera-relative movement
Clean and reusable architecture
Easy to expand with new states and abilities
